# Velvet-Barbet - Sistema Móvil de Gestión y Experiencia de Cliente

> **Solución móvil híbrida** orientada al agendamiento flexible, control de estaciones de atención y seguimiento de citas en tiempo real para **Barbería de Autor** y **Spa de Uñas Premium**.

---

## 📌 1. Visión General del Proyecto

 **Velvet & Blade** hemos consolidado un modelo de atención integral de imagen personal que combina dos líneas de servicio especializadas:
* **Blade (Barbería de Autor):** Cortes de precisión, perfilado de barba y tratamientos faciales.
* **Velvet (Spa de Uñas Premium):** Manicura rusa, pedicura spa y esmaltado permanente.

Debido al alto flujo de clientes en nuestras instalaciones, este proyecto nace con el objetivo de **eliminar la saturación en la recepción**, organizar eficientemente los turnos por estación de trabajo (*sillones de barbería* y *mesas de manicura*) y ofrecer una experiencia móvil ágil, transparente e intuitiva tanto para clientes como para el personal.

## 🛠️ Tecnologías Utilizadas

* **Framework Móvil Híbrido:** [Ionic Framework](https://ionicframework.com/) (Tabs Template)
* **Framework Web / Runtime:** Angular / TypeScript (o JavaScript)
* **Contenedor Nativo:** [Capacitor](https://capacitorjs.com/)
* **Estilos & UI:** Sass / SCSS con sistema de diseño personalizado (*Morado Velvet & Rojo Blade*)
* **Iconografía & Componentes:** Ionicons, Ionic UI Components (`ion-card`, `ion-datetime`, `ion-badge`, `ion-tabs`)
